# LumoAuth Guard for OpenClaw v0.1.1 (`v0.1.1`)

**Release Date:** November 20, 2026  
**Tag:** `v0.1.1` (signed)

## Package

| Package | Registry | Version |
| :--- | :--- | :--- |
| `@lumoauth/openclaw` | npm | `0.1.1` |
| `@lumoauth/openclaw` | ClawHub, publisher `lumoauth` | `0.1.1` |

The OpenClaw plugin id is `lumoauth`. Like 0.1.0, this release follows version 1 of the [LumoAuth Guard contract](https://github.com/lumoauth/agent-guard).

With this release, LumoAuth Guard is on ClawHub, OpenClaw's plugin registry and its default install source. The plugin's code is the same as in 0.1.0, and the Guard checks tool calls exactly as before. If you already run 0.1.0, you don't need to upgrade.

---

## Install

```sh
openclaw plugins install @lumoauth/openclaw
openclaw lumoauth setup
```

OpenClaw installs the plugin from ClawHub. It lists what the plugin registers and asks you to accept it. It no longer asks whether to install a plugin from outside ClawHub. In a script, add `--accept-capabilities` to the install command. You no longer need `--force`.

The install from npm still works: `openclaw plugins install npm:@lumoauth/openclaw`. OpenClaw then asks both questions from 0.1.0.

Setup hasn't changed. It asks for your LumoAuth dashboard address and a preset. Then it prints a link, a code and a key fingerprint. Open the link, check that the code and the fingerprint match your terminal, and approve the agent. If an OpenClaw gateway is running, restart it once with `openclaw gateway restart`.

**Requirements** (unchanged):

- OpenClaw 2026.11.5 or later.
- Node.js 24 or later.
- A LumoAuth organization. The Guard works on every LumoAuth plan. Approvals in the LumoAuth app, Slack and Discord need the Agent Governance add-on.

## What Changed

### 1. The Plugin Is on ClawHub

- ClawHub lists the plugin as **LumoAuth Guard**, in the **security** category, from the publisher `lumoauth`.
- ClawHub links the release to its source: the repository `LumoAuth/openclaw`, the tag `v0.1.1` and the commit `8b70d3b`.
- ClawHub serves the same tarball as npm. Both registries record the same SHA-512 integrity (see [Compatibility and Verification](#compatibility-and-verification)).

### 2. One New Field in `package.json`

`openclaw.build.openclawVersion` names the OpenClaw release that the plugin is built and tested against: `2026.11.5`. ClawHub requires this field, and 0.1.0 didn't have it.

The rest of the package is the same as in 0.1.0: the code, the copy of the contract, the `lumoauth-guard` skill, the settings and the files that the Guard keeps on your machine. Only the version number changed in `openclaw.plugin.json`.

## Known Limitations

The [limitations of 0.1.0](./v0.1.0.md#known-limitations) still apply, except the last one: the plugin is now on ClawHub. There are two new ones:

- **ClawHub's scan marks 0.1.1 as suspicious.** ClawHub runs an automated security scan on every release, and it rated this package `suspicious`. OpenClaw still installs the plugin from ClawHub, and records the install as `review-required`. The code is the same as in 0.1.0.
- **No provenance.** The package has no npm provenance attestation. On ClawHub, the release is `source-linked`: ClawHub checked the package's structure and linked the release to its source, but no build provenance exists.
